# exemples/ — facultatif, non noté

Ce dossier montre où mène le dépôt. À lancer après le rendu, par curiosité.

- `train_sentiment.py` : entraîne un TF-IDF + régression logistique sur
  `data/sample_reviews.csv` (semaine 2 en miniature) et sauvegarde le modèle
  dans `models/`.
- `app_streamlit.py` : petite interface de démonstration (semaine 5 en
  miniature) : `streamlit run exemples/app_streamlit.py`.
