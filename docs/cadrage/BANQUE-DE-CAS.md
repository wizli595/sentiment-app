# Banque de cas : douze besoins à cadrer

Cas de rechange pour s'entraîner avec la grille et l'arbre de choix
(`python scripts/new_cadrage.py cas4-mon-sujet` crée une fiche vierge).

## Entreprise

1. Détecter les factures fournisseurs en double avant paiement.
2. Prévoir les ruptures de stock d'un entrepôt à partir de l'historique des ventes.
3. Rédiger les descriptions produit d'un catalogue e-commerce.

## Citoyens

4. Répondre aux questions sur les démarches d'état civil à partir des textes officiels.
5. Détecter les fuites d'eau à partir des relevés de compteurs communicants.
6. Trier les signalements citoyens (voirie, éclairage, propreté) vers le bon service.

## Université

7. Vérifier qu'un dossier d'inscription contient toutes les pièces exigées.
8. Détecter le plagiat entre rapports de stage d'une même promotion.
9. Répondre aux questions des étudiants sur le guide des études, avec citation.

## État

10. Prioriser les courriers des usagers d'une administration selon l'urgence.
11. Détecter les déclarations fiscales incohérentes avec les revenus connus.
12. Résumer les cahiers de doléances d'une consultation publique.
